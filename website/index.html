اتجاه القبلة

حصن المسلم

✦ الأسئلة الشائعة

أسئلة يكثر طرحها

نعم، التطبيق مجاني بالكامل ومفتوح المصدر، بلا إعلانات ولا اشتراكات.

غالبية المحتوى — القرآن، الأذكار، مواقيت الصلاة، القبلة — يعمل بدون إنترنت.

لا. التطبيق لا يطلب حساباً ولا يجمع ولا يشارك أي بيانات شخصية؛ كل المحتوى مخزّن على جهازك.

الموقع فقط لتحديد مواقيت الصلاة واتجاه القبلة، والإشعارات للأذان. تدار من إعدادات الجهاز.

ببساطة: حذف التطبيق من جهازك يحذف كل بياناتك نهائياً، لأنها لا تُخزَّن في أي مكان آخر.

التحديثات تصل تلقائياً عبر Google Play، وعبر GitHub Releases لأي إصدار جديد.
