# خطة تحسين الهيدر العلوي

> نسخة منقّحة ومثبّتة بناءً على قرارات المستخدم بعد المراجعة.

## الهدف

تحويل الهيدر من (أيقونة + اسم التطبيق + أزرار) إلى هيدر احترافي صغير يعرض:

1. اسم الصفحة الحالية (بدل اسم التطبيق والأيقونة).
2. ساعة حالية بنظام 12 ساعة بخط صغير (أرقام لاتينية، ص/م بالعربية).
3. مفتاح تبديل الثيم (ليلي/نهاري) بطريقة عصرية.
4. زر رجوع في الصفحات الفرعية.
5. هيدر أصغر حجماً، مع **إبقاء خلفية الهيدر بنفس الألوان** (`--header-gradient`).

تمت إزالة زر الإعدادات من الهيدر نهائياً — فهو موجود في قائمة التنقل السفلية.

## الملفات الجديدة

### `src/utils/headerTitle.mjs`

دالة `getHeaderTitle(pathname)` تُرجع اسم الصفحة المحسوب من المسار:

| المسار | العنوان |
|---|---|
| `/home` | الرئيسية |
| `/quran` | المصحف |
| `/quran/:i` | «سورة اسم السورة» من `SURAHS[i].Name` |
| `/adhkar` | الأذكار |
| `/adhkar/:k` | اسم التصنيف من `getCategory(k).category` |
| `/hisn` | حصن المسلم |
| `/hisn/:id` | اسم الباب من `getCategoryById(id).category` |
| `/prayer` | المواقيت |
| `/tasbih` | المسبحة |
| `/radio` | الراديو |
| `/reciters` | القرّاء |
| `/reciters/:id` | اسم القارئ من `getReciter(id).name` |
| `/quiz` | الأسئلة |
| `/quiz/*` | الأسئلة (بدون تحميل ملف `IslamicQuiz.json` الكسول ~2.4MB) |
| `/settings` | الإعدادات |
| غير معروف | اسم التطبيق |

الاحتياطات:

- عند مسار فرعي لا يُحلّ اسمه (محذوف/خاطئ) → نعود لاسم القسم العام.
- لا تستورد بيانات الكويز الكسولة من الهيدر.

### `src/hooks/useClock.mjs`

- هوك `useClock()` يعيد الوقت الحالي بتنسيق 12 ساعة.
- يتحدَّث عند بداية كل دقيقة عبر `setTimeout` مضبوط لحد الدقيقة التالية (لا انحراف ولا عمل زمني زائد).
- التنسيق: أرقام **لاتينية** بصيغة `9:45 م` / `9:05 ص` (علامة ص/م بالعربية).
- `dayPeriod` يُحسب من `getHours() < 12`. الساعة 12 = 12، و0 = 12.

## تعديل `src/components/layout/Header.jsx`

هيكل RTL الجديد:

```
[رجوع؟] [اسم الصفحة]          [الساعة] [مفتاح الثيم]
```

- حذف: الشعار، اسم التطبيق، أيقونة الإعدادات.
- `h1.header__title`: اسم الصفحة من `getHeaderTitle(pathname)`.
- زر رجوع دائري صغير (يظهر فقط بمسارات فرعية: أكثر من مستوى واحد) → `navigate(-1)`، `aria-label="رجوع"`.
- الساعة: `useClock()` بخط صغير `text-muted`.
- مفتاح الثيم:
  - `role="switch"` + `aria-checked={theme === 'light'}` + `aria-label`.
  - حبة دائرية (أيقونة شمس/قمر) تنزلق بين طرفي المسار البيضاوي مع دوران الأيقونة وتغيّر لون المسار/التوهج حسب الثيم.
  - بدون نص، transition ناعمة على `transform` و `background`.

## تحسينات لاحقة

### مفتاح الثيم — خلفية أجمل

- المسار (Track) أصبح تدرّجاً سماوياً حقيقياً بدل التدرج المخضرّ السابق:
  - ليلي: تدرّج أزرق داكن + توهّج دائري بنفسجي عند موضع الحبة + حدود بنفسجية فاتحة.
  - نهاري: تدرّج ذهبي دافئ (شفق) + توهّج عند الحبة + حدود كهرمانية.
- أُضيفت أيقونتا شمس/قمر شفافتان (Ghost) في طرفي المسار تُظهر الوضع المقابل للتبديل — تتلاشى خلف الحبة وتتغيّر ألوانها حسب الثيم.
- الحبة: كريمي شمسي نهاري / سطح بنفسجي ليلي، مع توهّج مخفف. حركة `translateX` مع دوران سلس.

### إزالة التكرار (زر الرجوع + العنوان داخل الصفحات)

بما أن الهيدر يعرض الآن اسم الصفحة + زر رجوع، حُذفت العناصر المكرّرة وأُسنِدت للهيدر:

| الصفحة | المحذوف | المُبقى |
|---|---|---|
| قارئ القرآن `/quran/:i` | زر «السور» + اسم السورة | الوصف (مكية • عدد الآيات) + أدوات الخط/المرجع + تنقّل السور |
| الأذكار `/adhkar/:k` | زر «الأقسام» + العنوان | عددّ الأذكار في الشريط |
| حصن المسلم `/hisn/:id` | زر «الأقسام» + العنوان | عددّ الأذكار في الشريط |
| صفحة القارئ `/reciters/:id` | زر «القرّاء» + الاسم/الرواية | الرواية كـ"شريحة" صغيرة + نسبة المحفوظة |
| أسئلة `/quiz/:c` | زر «المجالات» | ملخص التقدم في الشريط |

- أُزيلت أزرار `onBack` غير المستخدمة من العناصر والورث، وحُذف CSS الميت
  (`.quran-reader__back`, `.quran-reader__surah-name`, `.adhkar-list__title`,
  `.hisn-list__title`, `.rec-detail__title`).
- زُرّيت الأشرطة المتبقية (العداد العددي فقط) بـ `justify-content: flex-end`
  للحفاظ على موقعها السابق.
- أُضيف `.rec-detail__rewaya` لحفظ معلومة رواية القارئ التي كانت حصرياً في العنوان المحذوف.

### زر الرجوع للصفحات الرئيسية غير الموجودة في شريط التنقل

الصفحات الجذرية التي تظهر في الشبكة الرئيسية **وليست** ضمن شريط التنقل السفلي
(حصن المسلم، المسبحة، الراديو، القرّاء، الأسئلة) أصبح لها زر رجوع في الهيدر إلى
القائمة الرئيسية `/home`، لأنها تُفتح من الشبكة الرئيسية مباشرة.

سلوك زر الرجوع في الهيدر:

| الحالة | زر الرجوع |
|---|---|
| صفحات شريط التنقل (`/home`, `/quran`, `/prayer`, `/adhkar`, `/settings`) | لا زر رجوع |
| صفحات رئيسية خارج الشريط (`/hisn`, `/tasbih`, `/radio`, `/reciters`, `/quiz`) | `navigate('/home')` |
| صفحات فرعية (سورة، قارئ، باب…) | `navigate(-1)` (الصفحة السابقة) |

- `getHeaderMeta` يحسب الصفحات الجذرية من `NAV_ITEMS` ناقص `BOTTOM_NAV_ITEMS`
  تلقائياً (بدون تكرار يدوي).
- القيمة الناتجة `back` تكون: `null` / `'history'` / مسار مثل `'/home'`.

- مراجعة يدوية عبر `npm run dev` في الوضعين الليلي/النهاري وعبر الصفحات الفرعية.
