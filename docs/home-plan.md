# خطة إعادة تصميم الصفحة الرئيسية + توحيد أيقونات التطبيق

> الخطّة المعتمدة — نسخة نهائية بعد مراجعة المستخدم وقراراته:
> 1) نطاق الأيقونات: داخل التطبيق فقط.
> 2) محتوى الرئيسية: التاريخ الهجري/الميلادي، مواقيت الصلاة + العداد،
>    أذكار الصباح/المساء حسب الوقت، متابعة القراءة، إحصاءات اليوم
>    (تسبيح/أذكار/سلسلة)، آية اليوم أو ذكر اليوم.
> 3) شكل شبكة التنقل: دوائر صغيرة ملونة.

## المشكلة

- `HomeScreen.jsx` شبكة 13 بطاقة كبيرة = مجرد قائمة انتقالات بلا قيمة للمستخدم.
- `Icon.jsx` أيقونات من مصادر وأنماط متضاربة (Material ممتلئ + Feather خطي)
  بلا توحيد — والرموز لا تدل بوضوح على فئتها.
- خلل: `map-pin` مستخدمة في `PrayerScreen.jsx` لكنها غير معرّفة في `Icon.jsx`
  فتُعرض أيقونة المنزل مكانها.

## الأهداف

1. صفحة رئيسية تخدم المستخدم فوراً: تاريخ هجري، عداد الصلاة القادمة، آية/ذكر
   اليوم، أذكار الصباح/المساء حسب الوقت، متابعة القراءة، إحصاءات اليوم.
2. شبكة تنقّل **دوائر صغيرة ملونة** بتسميات قصيرة وحركة ضغط لطيفة.
3. توحيد كل أيقونات التطبيق على **نمط خطي موحّد** (stroke) مع خريطة أيقونات
   منطقية تدل على الفئة + تلوين مميز لكل قسم.

## الملفات الجديدة

### `docs/home-plan.md`
هذا الملف.

### `src/services/daily.mjs`
خدمة المحتوى اليومي — قابلة للاختبار، بدون أي استيراد للمكوّنات:

| الدالة | الوصف |
|---|---|
| `todayVerse()` | آية اليوم من قائمة آيات شهيرة مُوْثقة (سورة، آية) تُدور حسب يوم السنة، والنص يُحضَر من مصحف التطبيق نفسه (`parseSurah`) |
| `todayDhikr()` | ذكر اليوم يُدور في أذكار `hisnmuslim.json` الحقيقية ذات الأسانيد |
| `isMorning(date)` | قبل الظهر (12:00) = صباح، بعده = مساء |
| `pickAdhkarCategory()` | يعيد مفاتيح `morning` / `evening` حسب الوقت |
| `todayHomeStats()` | تسبيح اليوم (`getTodayCounts`)، أذكار اليوم + السلسلة (`computeStats`) |

قواعد الثبات: نفس اليوم ميلادي → نفس الآية/الذكر دائماً (رقم يوم السنة ثابت)،
بلا حالة عابرة.

### `src/components/home/` — مكوّنات الصفحة الرئيسية
| المكوّن | المحتوى |
|---|---|
| `HomeHero.jsx` | التاريخ الهجري بخط `Quran` ذهبي + الميلادي + الموقع |
| `PrayerCard.jsx` | الصلاة القادمة + عداد تنازلي حي + الصلوات الخمس (من `getWatchSnapshot`)؛ نقرة → `/prayer` |
| `DailyVerse.jsx` | آية اليوم أو ذكر اليوم + المرجع + زر التفسير |
| `DailyAdhkar.jsx` | ذِكر الصباح/المساء حسب الوقت + زر يفتح القسم المناسب |
| `ContinueRow.jsx` | «تابع من حيث وقفت» (من `quran.reading`) + شارات إحصاءات اليوم |
| `FeatureGrid.jsx` | دوائر صغيرة ملونة لكل قسم في `NAV_ITEMS` |

### `tests/daily.test.mjs`
- ثبات اليوم: نفس التاريخ → نفس الآية/الذكر.
- صحة المراجع: كل آية مرجعها داخل حدود سورتها (لا انهيار).
- منطق صباح/مساء حول حد الظهر.

## الملفات المعدّلة

### `src/constants/app.mjs`
- إضافة `short` (تسمية قصيرة للدوائر) و `accent` (لون القسم) لكل عنصر في
  `NAV_ITEMS`.

### `src/components/ui/Icon.jsx`
- إعادة كتابة كل المسارات بنمط **خطي موحّد**:
  `fill="none" stroke="currentColor" strokeWidth={2}` + حواف دائرية.
- دعم الأيقونات الممتلئة (عبر `fill` اختياري داخل تعريف المسار) للرموز
  المفعلة: `star-fill`, `bookmark-fill`.
- خريطة أيقونات منطقية لكل قسم (تدل على الفئة):
  القرآن=مصحف، التفسير=كتاب مفتوح، الأذكار=كف، حصن=درع، المواقيت=مسجد،
  المسبحة=سبحة، الراديو=إذاعة، القرّاء=ميكروفون، الأسئلة=علامة استفهام،
  التاريخ=لفافة، الفتاوى=ريشة، الخطب=منبر، الإعدادات=مفتاح، الرئيسية=بيت.
- إضافة `map-pin` (تُستخدم في صفحة المواقيت ولا وجود لها حالياً — خطأ).

### `src/screens/HomeScreen.jsx`
- إعادة بناء كاملة: يتركّب من المكوّنات السبع أعلاه بترتيب قيّم.

### `src/styles/global.css`
- استبدال `.home__hero` / `.home__grid` / `.feature` بأنماط `.home-*` الجديدة
  (هيرو، بطاقة صلاة، آية اليوم، شبكة دوائر...). حذف الأنماط القديمة.

## التحقق

- `npm run test`
- `npm run build`
- مراجعة يدوية عبر `npm run dev` في الوضعين ليلي/نهاري وRTL.
- فحص أن كل اسم أيقونة مستخدم معرّف في `Icon.jsx` (سكربت سريع).
- تأكيد نصّ «آية اليوم» مطابق للآية الشهيرة المقصودة عند كل مرجع (تحقق يدوي
  يعيد طباعة النص لكل مرجع).
