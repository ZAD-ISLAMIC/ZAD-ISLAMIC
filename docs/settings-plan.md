# خطة صفحة الإعدادات الموحّدة (Settings Hub)

## القرار المعتمد

- صفحة إعدادات مركزية واحدة (`/settings`) تجمع كل إعدادات التطبيق المبعثرة، بنمط **بطاقات + صفحات فرعية** (Material 3 على أندرويد).
- الإعدادات البسيطة (مفاتيح/قوائم قصيرة) تبقى **inline** في الصفحة الرئيسية، والمعقّدة (حساب المواقيت، الأذان، التنزيلات، البيانات، الدعم) في صفحات فرعية.
- الأدوات السريعة الحالية (زر الثيم في الهيدر، شيت إعدادات المواقيت، سرعة المشغّل في PlayerBar) تبقى **مكانها** وتتزامن تلقائياً لأن كل صفحة فرعية تعيد استخدام نفس الخدمات/المفاتيح — لا تكرار تخزين.
- الثيم يدعم الآن ثلاث قيم: `system | dark | light`.

## البنية

### المسارات

```
/settings              ← الصفحة الرئيسية (إعادة كتابة SettingsScreen.jsx)
/settings/reading      ← الخطوط والقراءة (مصحف + تفسير + استمرارية)
/settings/prayer       ← حساب المواقيت (طريقة الحساب، المذهب، التنسيق، الدقائق، الزوايا)
/settings/adhan        ← الأذان والتنبيهات + الصلاحيات
/settings/location     ← الموقع (GPS / قائمة / يدوي)
/settings/downloads    ← التنزيلات والتخزين لكل قسم
/settings/data         ← البيانات والخصوصية (تصفير التقدم)
/settings/support      ← الدعم والتبرع (تحويل بنكي + تواصل)
/settings/about        ← حول التطبيق
```

كلها `lazy` في `App.jsx`، وعناوينها تُسجَّل في `headerTitle.mjs` (عنوان + `back = '/settings'`).

### المكوّنات (`src/components/settings/`)

| المكوّن | الوظيفة |
|---|---|
| `SettingsGroup.jsx` | عنوان القسم + البطاقة الحاوية |
| `SettingsRow.jsx` | صف موحّد: أيقونة + تسمية + وصف + تحكم |
| `SettingsSwitch.jsx` | صف بمفتاح تبديل |
| `SettingsNavRow.jsx` | صف تنقّل بقيمة + chevron |

| `SettingsSlider.jsx` | منزلق |

### الخدمات

- **جديدة**: `src/services/settingsStorage.mjs` — `getStorageStats()` يجمع `bytes/count` من سجلات القرّاء (`reciters.reg.*`) وسجلات الملفات (`hisn.files.*`)، و`resetSection(ns)` يحذف ملفات قسم.
- **معدّلة**: `useTheme.mjs` — دعم `system` عبر `matchMedia('(prefers-color-scheme: dark)')`، مع إبقاء زر الهيدر متوافقاً (تبديل صريح).
- كل صفحة فرعية تعيد استخدام الخدمات الموجودة كما هي (مصدر حقيقة موحّد).

## تصميم الصفحة الرئيسية

- شريط بحث sticky يفلتر كل الصفوف فورياً.
- مجموعات: المظهر ← المواقيت والأذان ← الصوت والمشغّل ← التنزيلات والتخزين ← البيانات والخصوصية ← الدعم والتبرع ← حول التطبيق.
- كل بطاقة: خلفية `--bg-card`، زوايا `--radius`، حدود `--border`، فواصل رفيعة بين الصفوف.
- أيقونة الصف داخل مربع 40px بخلفية `--primary-soft` (التدميرية بـ `--danger-bg`).
- قيمة الصف الحالية بنص مطفي + chevron بلون `--primary`.
- الأنماط في ملف مستقل `src/styles/settings.css` يُستورد lazy مع الشاشات.

## المحتوى

### الرئيسية (inline)
- **المظهر**: الثيم segmented (تلقائي/ليلي/نهاري) + صف تنقّل «القراءة والخطوط».
- **المواقيت**: الموقع (قيمة = المدينة)، طريقة الحساب (قيمة = الطريقة)، مفتاح الأذان والتنبيهات، صوت الأذان (قيمة = الصوت).
- **الصوت**: سرعة التشغيل select، صوت المسبحة switch، اهتزاز المسبحة switch.
- **التنزيلات**: صف يعرض إجمالي الاستخدام.
- **البيانات**: صف أحمر للتصفير.
- **الدعم**: صف تنقّل.
- **حول**: صف تنقّل.

### صفحات فرعية
- **reading**: معاينة نص + steppers لأحجام خطوط المصحف (18–40) والتفسير (12–28) + صف استمرار القراءة بمسح.
- **prayer**: نقل أقسام الحساب من `SettingsSheet.jsx` إلى صفحة (طريقة/مخصص/مذهب/تنسيق/خطوط عالية/دقائق) مع `updateConfig` + `refreshWatch`.
- **adhan**: مفتاح التشغيل + «جرّب الآن» + قائمة الأصوات + استيراد مخصص + حجم (slider) + احترام وضع الصوت + لوحة الصلاحيات.
- **location**: GPS / قائمة مدن / يدوي (يعيد استخدام `location.mjs` + `geo.mjs`).
- **downloads**: إجمالي الاستخدام + كل قسم (قرّاء/حصن/فتاوى/خطب) مع الحجم وعدد الملفات وزر حذف مؤكَّد.
- **data**: تصفير الكويز / حصن / الأذكار / مسح كل البيانات مع `SettingsConfirm`.
- **support**: بطاقة ذهبية «صدقة جارية» + تحويل مصرف الراجحي (ريان المالكي، IBAN `SA5980000201608016047562`، Swift `RJHISARI`) بأزرار نسخ + بريد `rn0x.me@gmail.com`.
- **about**: الاسم، النسخة، نبذة، المحتوى والمصادر، مشاركة.
